# Задание 3. Внешние итеграции

### Подключение интелектуального шлагбаума

1. Взаимодействие с внешней системой строиться по REST на базе HTTPS протокола. 
2. В качестве протокола авторизации имеет смысл использовать SAML, т.к. есть только back-to-back взаимодействие
3. Используется только 2 метода для взаимоействия, которые исключают передачу от компании PropDevelopment каких либо персональных данных пользователей:
- Метод ручного открытия шлакбаума где передается только идентификатор шлагбаума и уникальный идентификатор команды открытия. Для обоих индентификторов будем использовать GUID, чтобы исключить подбор.
- Callback метод от провайдера в котором передается распознанный номер автомобиля и идентификатор шлагбаума, проверка соответствия осуществляется уже внутри нашей системы


### Подключение интелектуального домофона

1. Взаимодействие с внешней системой строиться 
- по REST на базе HTTPS протокола (основной сервис для управления)
- по RTSP (Real Time Streaming Protocol) для потокового сервиса предоставлюего видео с видеодомофона
2. В качестве протокола авторизации имеет смысл использовать SAML. 
3. Для получения доступа к видео будем использовать модель доступа Just-In-Time (JIT) для авторизации. Т.е. будет выдавать временный доступ на получение видеоинформации
4. При работе с биометрией будем использовать следующий подход:
- данные изображений будут храниться на нашей стороне
- стороннему провайдеру изобрадения будут предоставляться только для снятия биометрических данных и далее исходное изобрадежение удаляется на его стороне.
- для передачи изображений дополнительно будем использовать гоморфное шифрование
